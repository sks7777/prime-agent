- Fixed cross-thread ACP session adoption: `session/new` no longer reuses an existing session matched by cwd, always minting a fresh ACP session id. Previously two bb threads sharing one environment (same cwd) could claim the same `providerThreadId`, causing 409 `provider_session_unavailable` errors. Removed `find_session_by_cwd` and `scan_session_dir_ranked` (dead code after the fix); `session/load` and `session/fork` still resolve by ACP id for reconnects.
