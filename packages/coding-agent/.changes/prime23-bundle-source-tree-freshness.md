- Bound worker-bundle freshness to the source tree identity: bundle.mjs records a content-addressed `sourceTreeId` (commit sha, or the `git stash create` sha of a dirty tree) next to the build id, the launcher exports it as `PRIME_AGENT_SOURCE_TREE_ID`, and the supervisor prefers it over the collision-prone `git describe` string — a `--source` supervisor no longer adopts a bundle built from different dirty source. The build id and package version remain fallbacks, and the decision is a pure exported function covered by unit tests.
