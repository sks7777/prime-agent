- Fixed bb-mirror rebind hardening: cancelling a parked deferred child now settles it instead of wedging the parent's quiescence barrier, a failed re-admission rolls back to the draft session and only re-attaches a known draft, concurrent rebinds and session/new are fenced, and the mirror wait timer no longer leaks an unhandled rejection or keeps the worker event loop alive.
